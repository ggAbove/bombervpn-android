# Bomber VPN native Android surface

Audience: ordinary Russian-speaking VPN customers. Operate mode. Import the account subscription, choose a server, connect, and recover without learning proxy terminology. Android Compose / Material 3; existing service engine remains the owner of connection truth.

## Direction contract
THESIS: A dependable BomberVPN connection control, with advanced server management one tab away.
OWN-WORLD: Existing BomberVPN Ink/Mist identity, amber primary actions, signal-bomb vector mark; native Material 3 components and system typography. The brand is pinned by the user.
STORY: Import → choose server → connect → test internet access. Account and support remain in the established Telegram service.
FIRST VIEWPORT: App bar, centered signal mark and real state, full-width primary connection button, selected-server button, subscription actions; compact bottom navigation or expanded rail. Home/help content caps at 560dp.
FORM: Native task surface; code-first adaptation of the existing brand, no raster comp and no concept lottery for this pinned identity.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

No new shipping raster assets: the mark is an XML vector adapted from the owner's existing BrandMark.vue; inherited upstream raster assets are unchanged. Review screenshots are runtime evidence, not product artwork.

## Workflow scope
This extends the existing v2rayNG MainScreen and applies the owner's established BomberVPN identity through native Material roles; it does not create a replacement visual world. Applicable new-work.md §3: “Extend an existing surface … Inherit its world and composition. Resolve only the new purpose, content, hierarchy, states, interaction … No concept tournament.” The parent interpreted the brand/platform-pinned adaptation under that extension branch. No seed was rolled, and no retrospective seed or comp approval is claimed. Review against native task clarity and the fixed identity; record this interpretation explicitly.

## Quality bar
A customer can distinguish setup, ready, and running at a glance; find subscription import without opening advanced settings; reach help and support; use native font scaling and navigation at phone/tablet widths. Brand color serves actions and state, never fabricated health metrics.
